
1. *Instalar dependencias del proyecto:*
   
   npm install
   
2. *Instalar las herramientas de Firebase (si no las tiene):*
   
   npm install -g firebase-tools
   
3. *Iniciar sesión en Firebase con su cuenta de Google autorizada:*
   
   firebase login
   
4. *Compilar y desplegar la aplicación:*
   
   npm run build
   firebase deploy
